# 音效檔

遊戲會用到的六個聲音。檔名**必須**照下表，程式是照名字去找的。

| 檔名 | 什麼時候播 | 長度大概 |
|---|---|---|
| `ball.mp3` | 玩家按下「壞球」 | 0.3～1 秒 |
| `strike.mp3` | 玩家按下「好球」 | 0.3～1 秒 |
| `catch.mp3` | 球進捕手手套 | 0.2～0.5 秒 |
| `happy.mp3` | 判決正確 | 0.5～1.5 秒 |
| `boo.mp3` | 誤判 | 0.5～2 秒 |
| `fans.mp3` | 球場背景人聲，**整場循環播放** | 20～40 秒，頭尾要接得順 |

## 格式

用 **MP3**。iPhone 的 Safari 一定支援，OGG 則完全不支援，WAV 可以但檔案會大好幾倍。
M4A／AAC 也可以。

## 大小

這些檔案會跟遊戲一起被存進手機供離線使用，所以總大小會直接加到離線包上。
目前離線包約 3.7 MB。六個音效建議控制在 1 MB 以內，其中 `fans` 會佔掉大部分。

短音效用 128 kbps 單聲道就很夠；`fans` 背景聲用 96～128 kbps 就好，它本來就是墊底的。

## 加進來之後要做的事

1. 把檔案放進這個資料夾
2. 加進 `sw.js` 的預先快取清單（`SHELL`），否則離線時會沒有聲音
3. 把 `sw.js` 的 `VERSION` 加一

沒有放檔案的話，`sfx.js` 會退回用程式合成的聲音，遊戲不會壞掉。
